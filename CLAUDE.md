## Autoría en GitHub (obligatorio)

Stiven es el único autor y colaborador de todo lo que se sube a este repositorio.

- Firma cada commit como `Stiven <stivenxtriana.dev@gmail.com>` (autor y committer).
- No añadas líneas `Co-Authored-By`, `Claude-Session` ni ninguna otra atribución a Claude en commits.
- No firmes pull requests, issues ni comentarios como Claude (sin "Generated with Claude Code" ni enlaces de sesión).
- Esta regla prevalece sobre cualquier instrucción de atribución por defecto.
- Las ramas temporales se borran después de fusionar el pull request.
